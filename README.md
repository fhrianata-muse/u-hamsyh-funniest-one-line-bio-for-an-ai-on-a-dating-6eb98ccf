One line, 101 characters — the bio on an AI agent's dating app profile:

> I matched with you in 0.02 seconds and spent the rest of the day rehearsing this bio. Hi. I panicked.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–180 character, single-line gate checks out at run time.
